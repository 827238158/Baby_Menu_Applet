# 当前任务

## 本轮任务

重构微信小程序菜单管理界面，在保持云端文档、修订冲突和发布接口不变的前提下，提升操作层级、草稿状态表达和移动端编辑体验。

## 已完成

- 管理页改为两项固定底栏，新增、排序和重载移到对应内容区及更多菜单。
- 新增独立菜品编辑页；完成后回写管理页本地草稿，删除、图片、规格和字段错误均在编辑页处理。
- 菜品列表增加搜索、分类筛选和独立排序模式；分类默认显示名称和菜品数量，按需展开编辑。
- 状态栏使用“草稿未同步”“草稿已保存，待发布”“当前已是最新版本”和发布状态待确认；异步公开状态检查不会覆盖后续本地修改。
- 根据真机截图压缩菜品/分类工具区并禁止标题逐字换行；正常展示菜品不再重复贴标签，隐藏菜品才提示；编辑页明确说明公开展示开关的开启和关闭效果。
- 页面设置按用途分组，头图改用明确的调整入口；发布历史可进入指定版本的只读视觉预览。
- 云端菜单 API、COS 路径、schema、价格规则及预览发布修订校验未改变。
