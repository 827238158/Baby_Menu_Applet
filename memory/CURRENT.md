# 当前任务

## 本轮任务

修复心愿夹删除动画竞态和缩略图失败后的孤儿原图清理时序。

## 目标与验收

- 删除卡片退场动画期间，即使分页或图片回调更新列表，也不覆盖新状态或跳过分页数据。
- 原图上传成功但缩略图上传失败时，等待孤儿原图清理请求结束后再返回原始错误。
- 不修改登录限流、令牌 `iat` 校验和非 JSON 2xx 响应行为。

## 影响区域

- `miniprogram/pages/gifts/gifts.js`
- `miniprogram/services/gift-api.js`

- `minitest/gift-api.test.cjs`

- 缩略图上传失败后会等待对应命名空间的孤儿原图清理请求完成；清理失败仍不覆盖原始上传错误。
