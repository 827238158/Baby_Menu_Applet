# 自用菜单小程序
## 项目说明

微信原生家庭菜单：公开浏览云端菜单，本地选择规格、加入购物车并复制已选清单。没有支付、真实订单或数据库，菜品价格统一为字符串 `'0'`。

本小程序为家庭内部自用工具。菜品数据统一存储于腾讯云，支持在管理界面完成图文信息的编辑、更新与维护。

管理后台采用微信 ID 白名单机制鉴权，无账号登录流程，仅白名单内家庭成员可访问。内置礼品夹、装修好物收藏模块，用于记录、收藏日常心仪物品，同样仅限家庭成员访问使用。非白名单用户打开小程序仅能查看菜单界面。开发流程见 [开发指南](开发指南.md)，可参照开发流程二次搭建属于自己的小程序工具。

本小程序点单后仅能复制点餐信息到剪贴板。如需实现真实点单场景和分享功能，需要自行通过微信认证。

## 日常使用与开发

- 菜单页长按店名标题（白名单用户） → 编辑 → 保存共享草稿 → 预览 → 发布。详见 [维护指南](CUSTOMIZATION.md)。
- 公开菜单首次进入和返回页面时自动检查版本；网络失败使用最近成功缓存。预览购物车与真实购物车隔离。
- 首次使用时由白名单管理员在菜单管理页创建内容、保存草稿、预览并发布菜单；之后云端为唯一真源。
- UI 规则只维护在 [DESIGN.md](DESIGN.md)，命令和验收统一维护在 [RUNBOOK](memory/RUNBOOK.md)。
